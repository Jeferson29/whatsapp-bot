# 🤖 WhatsApp Bot Multi-Persona

Um bot de atendimento e automação para WhatsApp, desenvolvido inteiramente em Node.js. Este projeto foi construído para gerenciar interações de forma inteligente, utilizando múltiplas personas e sistema de agendamentos.

## 🚀 Funcionalidades

- **Multi-Persona:** Capacidade de alternar entre diferentes perfis de atendimento dependendo do contexto da conversa.
- **Sistema de Agendamentos:** Registro e gerenciamento de dados automatizados (via `agendamentos.json`).
- **Conexão via QR Code:** Autenticação segura e em tempo real com a API do WhatsApp.
- **Desenvolvimento Mobile-First:** Todo o código e versionamento foram realizados via terminal (Termux) em ambiente mobile.

## 🛠️ Tecnologias Utilizadas

- **Node.js:** Motor principal da aplicação.
- **JavaScript (ES6+):** Lógica de programação e estruturação.
- **Baileys (WebSockets):** Biblioteca principal para a conexão direta com o WhatsApp Web.
- **Git/GitHub:** Versionamento de código.

## 💡 Sobre o Projeto

Este projeto demonstra conhecimentos práticos em consumo de APIs, manipulação de arquivos JSON em tempo real, lógica de roteamento de mensagens e gerenciamento de sessões contínuas no back-end.
